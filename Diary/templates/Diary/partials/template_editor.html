Tasks

Use milestone dates, annual dates, or dates calculated from another task. Date sources fix due dates; predecessors identify tasks that must finish first.

Task connections

Select a task to edit it. Boxes are tasks; diamonds are milestone dates. Solid arrows show completion prerequisites; dashed arrows show date sources. Save task accepts edits into this draft; Save template publishes the complete version.

Date positioning

Negative offsets place tasks above their source; zero and positive offsets place tasks below it. Zero means the same due date. Positions are schematic, not a calendar-day scale. Hover a date arrow for its offset. A solid completion arrow replaces a date arrow between the same tasks.
